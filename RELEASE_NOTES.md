# v0.10.1

A small fix to how the Study tab lists suspect readings.

- **Suspect readings** shows where each animal comes from. Stabled pets keep the **checkable** tag. Other pets are tagged **unstabled**, and animals from the community cache are tagged **community**. If you own a pet whose genome someone else also shared, it has their name, and before this it looked like their animal.
- The note "Stabled animals come first" shows only when the list has a stabled animal.
- Release builds no longer log an "Unexpected input" warning from the updater step. The updater file is uploaded as before.
